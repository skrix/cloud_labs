# Schedule

Мінімум задач API залежить від часу доби: **вдень 2**, **вночі 1**. Autoscaling працює поверх
розкладу — розклад змінює лише нижню межу.

Terraform: [`deploy/aws/terraform/schedule.tf`](../deploy/aws/terraform/schedule.tf).

| Сервіс | День (08:00–22:00 Kyiv) | Ніч (22:00–08:00 Kyiv) | Максимум |
|--------|-------------------------|------------------------|----------|
| API    | **2**                   | **1**                  | 4        |
| Worker | 1                       | 1                      | 4        |
| Redis  | 1                       | 1                      | 1        |

## Як це зроблено

- Дві `aws_appautoscaling_scheduled_action`: `api_day` о 08:00 ставить `min_capacity = 2`,
  `api_night` о 22:00 — `1`. Часовий пояс `Europe/Kyiv`, тож перехід на літній час враховано.
- Вранці друга задача додається одразу; ввечері зайву знімає target tracking після 15 хв низького
  CPU ([AUTOSCALING.md](AUTOSCALING.md)).
- Scalable target API ігнорує зміни `min_capacity`, інакше `terraform apply` перебивав би розклад.
- Змінні: `schedule_enabled`, `schedule_day_cron`, `schedule_night_cron`, `schedule_timezone`,
  `api_day_min`; нічний мінімум — `autoscaling_min`.

### Чому вночі 1, а не 0

На ECS Fargate запит не розбудить сервіс із 0 задачами: ALB без здорових цілей відповідає `503`,
а в target tracking за CPU немає метрики, від якої стартувати. Масштабування до нуля за запитами є
в Cloud Run і Azure Container Apps; на ECS воно потребує окремої логіки.

Worker теж лишається на 1 задачі: інакше показання, прийняті вночі, чекали б кілька хвилин на
старт worker'а.

## Місячна економія

Fargate, Linux/x86, eu-north-1: $0,0445 за vCPU-год, $0,0049 за ГБ-год. Задача 0,25 vCPU /
0,5 ГБ:

```
0,25 × 0,0445 + 0,5 × 0,0049 = $0,013575 за задачу-годину
```

Місяць — 730 год: день 14 × 30,42 = 425,8 год, ніч 10 × 30,42 = 304,2 год. Рахуються лише
мінімальні задачі; додані autoscaler'ом однакові в обох варіантах.

| Варіант                   | API, задачо-год            | Worker, задачо-год | $ / міс          |
|---------------------------|----------------------------|--------------------|------------------|
| 2 задачі API цілодобово   | 2 × 730 = 1460             | 730                | 29,73            |
| Розклад: 2 вдень, 1 вночі | 2 × 425,8 + 304,2 = 1155,8 | 730                | 25,60            |
| **Економія**              | 304,2                      | —                  | **4,13 (−14 %)** |

Розклад знімає одну задачу API на ніч: 304,2 × $0,013575 = **$4,13 на місяць** (−21 % вартості
API). Друга денна задача дає запас на пік (масштабування займає ≈ 5 хв) і на відмову однієї
задачі — ECS розміщує їх у різних зонах доступності; вночі цей запас не потрібен.

Не змінюються: Redis, RDS, ALB, SQS.
